## 1. โจทย์กิจกรรม (The Challenge)

ตะวันต้องส่งมอบระบบหลังร้านให้ยายนวลภายในคืนนี้ ให้เลือกภารกิจหนึ่งข้อ แล้วพัฒนาเป็นโปรแกรมไพธอนที่รันได้จริงภายในคาบ

- [ ] **ภารกิจ A — เครื่องคิดเงินอัจฉริยะ:** รับออเดอร์ต่อเนื่องจนพิมพ์คำว่า `จบ` แล้วออกใบเสร็จพร้อมยอดรวมและเมนูที่ขายดีที่สุดของบิลนั้น
- [ ] **ภารกิจ B — ระบบคิวหน้าเรือ:** จัดคิวลูกค้าแบบเข้าก่อนออกก่อนด้วย `deque` พร้อมปุ่มยกเลิกคิวล่าสุดด้วยสแตก
- [ ] **ภารกิจ C — กระดานเมนูขายดี:** สรุปยอดขายรายเมนูจากรายการออเดอร์ แล้วจัดอันดับจากมากไปน้อย พร้อมค้นหายอดของเมนูที่ระบุ
- [ ] **ภารกิจ D — บัตรสมาชิกคลองนีออน:** ค้นหารหัสสมาชิกจากฐานข้อมูลที่เรียงแล้วด้วย Binary Search พร้อมรายงานจำนวนรอบที่ใช้

**ข้อกำหนดร่วมของทุกภารกิจ**

1. ต้องใช้โครงสร้างข้อมูลอย่างน้อย 2 ชนิดที่ต่างกัน และอธิบายเหตุผลของการเลือกได้
2. ต้องแยกการทำงานออกเป็นฟังก์ชัน (`def`) อย่างน้อย 2 ฟังก์ชัน
3. ต้องจัดการกรณีผิดปกติอย่างน้อย 1 กรณี เช่น สั่งเมนูที่ไม่มีอยู่ หรือเรียกคิวขณะที่คิวว่าง

### ขั้นที่ 3 — Prompt Lab: ใช้ AI เป็นผู้ตรวจ 3 รอบ (25 นาที)

เปิดเครื่องมือ AI ได้แล้ว แต่ต้องใช้ตามบทบาท “ผู้ตรวจและผู้อธิบาย” เท่านั้น ทำครบทั้งสามรอบและบันทึกลงตาราง

| รอบ | เป้าหมายของรอบ | ตัวอย่างข้อความสั่งที่ควรใช้ |
|---|---|---|
| 1 | ให้ AI ชี้จุดที่ตรรกะผิด โดยยังไม่ให้โค้ด | “นี่คือรหัสเทียมและโค้ดของฉัน ชี้เฉพาะจุดที่ตรรกะผิดเป็นคำถามกลับมา ห้ามเขียนโค้ดให้” |
| 2 | ให้ AI อธิบายแนวคิดที่ยังไม่เข้าใจ | “อธิบายว่าทำไม `pop(0)` ถึงช้ากว่า `popleft()` ด้วยการเปรียบเทียบกับการต่อแถว” |
| 3 | ให้ AI เสนอทางเลือกโครงสร้างข้อมูล แล้วเราตัดสินใจเอง | “เสนอโครงสร้างข้อมูล 2 ทางเลือกสำหรับงานนี้ พร้อมข้อดีข้อเสียและ Big-O แต่ห้ามแก้โค้ดของฉัน” |

**ตารางบันทึกการใช้ AI (AI Log) — ต้องกรอกครบทั้ง 3 รอบ**

| รอบ | เครื่องมือ/เวลา | ข้อความสั่งที่ใช้ (ย่อ) | สิ่งที่ AI ตอบ (ย่อ) | สิ่งที่ฉัน **ปฏิเสธหรือแก้เอง** พร้อมเหตุผล |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |

> **กติกาจริยธรรมของขั้นนี้**
> 1. ห้ามคัดลอกโค้ดจาก AI มาวางทั้งก้อน ให้พิมพ์เองทุกบรรทัดที่ตัดสินใจรับมาใช้
> 2. ทุกบรรทัดที่ได้แนวคิดจาก AI ต้องเขียนคอมเมนต์กำกับว่า `# แนวคิดจาก AI ปรับแก้โดย <ชื่อ>`
> 3. ต้องมีอย่างน้อย 1 ข้อเสนอของ AI ที่นักศึกษา **ปฏิเสธ** พร้อมเหตุผลเชิงเทคนิค
> 4. โค้ดบรรทัดใดที่อธิบายไม่ได้ ให้ลบออกก่อนส่ง

**คำรับรอง:** ข้าพเจ้าเข้าใจโค้ดทุกบรรทัดที่ส่ง และพร้อมอธิบายด้วยวาจาเมื่ออาจารย์เรียกถาม
