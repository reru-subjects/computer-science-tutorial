## ขั้นที่ 2 — เขียนรหัสเทียมและผังงาน (25 นาที) · เดี่ยว · คอมพิวเตอร์ปิด

เลือกภารกิจหนึ่งข้อ แล้วทำต่อในขั้นที่ 3 ถึง 6 ด้วยภารกิจเดิม

- [ ] **ภารกิจ A (พื้นฐาน) — ใบเสร็จร้านยายนวล:** รับจำนวนชามและเงินที่ลูกค้าจ่าย คำนวณราคารวมชามละ 45 บาท ถ้าเงินพอให้แสดงเงินทอน ถ้าไม่พอให้แสดงว่าขาดอีกเท่าไร
- [ ] **ภารกิจ B (พื้นฐาน+) — นับลูกค้ากระเป๋าหนัก:** จากรายการยอดซื้อของลูกค้าทั้งวัน ให้นับว่ามีกี่คนที่ซื้อตั้งแต่ 100 บาทขึ้นไป และคิดเป็นร้อยละเท่าไรของลูกค้าทั้งหมด
- [ ] **ภารกิจ C (กลาง) — วันไหนขายดีที่สุด:** จากยอดขาย 7 วัน ให้หาว่าวันใดขายได้มากที่สุดและมากที่สุดเท่าไร โดยห้ามใช้คำสั่ง max()
- [ ] **ภารกิจ D (ท้าทาย) — จัดอันดับเมนู:** จากยอดขายของ 5 เมนู ให้เรียงจากมากไปน้อยด้วยการเรียงลำดับแบบเลือกที่เขียนเอง ห้ามใช้ sorted()

**2.1 วิเคราะห์โครง IPO ก่อน (5 นาที)**

| ส่วน | คำตอบของฉัน |
|---|---|
| Input — มีอะไรอยู่ในมือ | |
| Process — ต้องทำอะไรกับมัน | |
| Output — ต้องการเห็นอะไร | |

**2.2 เขียนรหัสเทียม (10 นาที)** เขียนลงกระดาษ ใช้คำสงวนของรายวิชาเท่านั้น (รับ / กำหนด / ถ้า–มิฉะนั้น / สำหรับ / ตราบใดที่ / แสดง) ใส่หมายเลขข้อทุกบรรทัด และย่อหน้าเข้าหนึ่งระดับเมื่ออยู่ใต้ “ถ้า” หรือ “สำหรับ”

**2.3 วาดผังงาน (10 นาที)** ใช้สัญลักษณ์ให้ถูกประเภท วงรี = เริ่ม/จบ, สี่เหลี่ยมด้านขนาน = รับ/แสดงข้อมูล, สี่เหลี่ยมผืนผ้า = ประมวลผล, สี่เหลี่ยมขนมเปียกปูน = ตัดสินใจ

> **ตรวจตัวเองก่อนไปต่อ** (ทำเครื่องหมาย ✓ ให้ครบทุกข้อ)
> ☐ ทุกลูกศรมีปลายทางชัดเจน ไม่มีเส้นลอย
> ☐ ทางแยกจากสัญลักษณ์ตัดสินใจ กลับมารวมกันหรือจบอย่างถูกต้อง
> ☐ ตัวแปรทุกตัวถูกกำหนดค่าเริ่มต้นก่อนถูกนำไปใช้
> ☐ ถ้ามีการทำซ้ำ มีบรรทัดที่ทำให้เงื่อนไขเปลี่ยนค่าได้จริง (ไม่วนไม่รู้จบ)
