#### Case C3 — ประเมินโมเดลทำนายผลผลิตด้วย MSE / RMSE / MAE (20 นาที)

ทีมลองโมเดลทำนายผลผลิต (kg/ไร่) กับ 3 แปลง ได้ข้อมูลเป็น **list ของ dict** (เหมือนสไลด์ List + Dicts):

```python
records = [
    {"plot": "RE-001", "actual": 460, "predicted": 450},
    {"plot": "RE-002", "actual": 510, "predicted": 530},
    {"plot": "RE-003", "actual": 395, "predicted": 380},
]
```

**ให้เขียนโปรแกรมที่**
1. ดึงค่า `actual` และ `predicted` ของแต่ละแปลงด้วย index + key แล้วคำนวณ error 3 ค่า
2. คำนวณ

   - MSE  = (e₁² + e₂² + e₃²) / 3
   - RMSE = √MSE (ใช้ `** 0.5`)
   - MAE  = (|e₁| + |e₂| + |e₃|) / 3 (ใช้ `abs()`)

3. เพิ่ม key `"error"` ลงใน dict ของแต่ละแปลง แล้วพิมพ์ `records` ทั้งก้อน
4. พิมพ์สรุปด้วย f-string ทศนิยม 2 ตำแหน่ง

**ผลที่ควรได้**
```
errors = 10, -20, 15
MSE  = 241.67
RMSE = 15.55
MAE  = 15.00
```

> 💡 คำถามชวนคิด: RMSE (15.55) มีหน่วยเดียวกับผลผลิต (kg/ไร่) แต่ MSE (241.67) ไม่ใช่ — ถ้าต้องรายงานให้เกษตรกรฟัง ควรใช้ตัวไหน? เพราะอะไร?

### ข. แนวเฉลย Checkpoint (สรุป)

- **A1** — `new_age = age` ไม่สร้างอ็อบเจ็กต์ใหม่ จึง id เท่ากัน; `+ 0.5` สร้าง float object ใหม่แล้วให้ `new_age` ชี้ไป ส่วน `age` ยังชี้ object เดิม (int เป็น immutable)
- **A2** — ทั้งหมดเป็น `SyntaxError`; `avg_yield_per_rai`; ตั้งทับ built-in แล้วจะเรียกฟังก์ชันเดิมไม่ได้ (เช่น `sum = 5` แล้ว `sum([1,2])` → `TypeError`)
- **A3** — `ValueError` ต้อง `int(float("20.52"))`; float เก็บแบบฐานสองจึงประมาณค่า ใน ML ห้ามเทียบ float ด้วย `==` ตรง ๆ; `35e-5` = 35 × 10⁻⁵
- **A4** — กลับลำดับสตริง; `>` ชิดขวา, `12` กว้าง 12 ช่อง, `,` คั่นหลักพัน, `.2f` ทศนิยม 2 ตำแหน่ง
  `print("%-14s%8.2f%7d%12.2f" % (name, price, kg, price*kg))` (วิธี `%` ไม่รองรับ `,` คั่นหลักพัน)
  `print("{:<14}{:>8.2f}{:>7d}{:>12,.2f}".format(name, price, kg, price*kg))`
- **A5** — `print(sum(plots) / len(plots))` ได้ `500.8333…`; `b = a` คือชี้ object เดียวกัน; `TypeError` — พิกัดไม่ควรถูกแก้โดยไม่ตั้งใจ
- **A6** — set ไม่มีลำดับ ใช้ `sorted()` เพื่อให้ผลลัพธ์คงที่ (สำคัญต่อ reproducibility); `[]` เกิด `KeyError` ถ้าไม่มี key, `.get()` คืนค่า default; `{}` เป็น `dict`, set ว่างใช้ `set()`

### ค. โค้ดเฉลย Case Study

```python
# ===== C1 =====
text = input("Enter plot data: ")              # RE-014,Suwannaphum,32,14720,16.25
parts = text.split(",")
plot_id  = parts[0].strip()
district = parts[1].strip()
area_rai = int(parts[2])        # int(" 32 ") ใช้ได้ เพราะ int() ตัดช่องว่างหัวท้ายให้เอง
yield_kg = float(parts[3])
price_kg = float(parts[4])

yield_per_rai = yield_kg / area_rai
revenue = yield_kg * price_kg
print(f"{plot_id:<8}{district:<14}{area_rai:>5d}{yield_per_rai:>10.2f}{revenue:>14,.2f}")
print(type(area_rai), type(yield_kg), type(price_kg))
# RE-014  Suwannaphum      32    460.00    239,200.00

# ===== C2 =====
review = "  ข้าวหอม หอมมาก หุงขึ้นหม้อ หอมมาก ราคาดี  "
words = review.strip().split()
unique_words = set(words)
print(len(words), len(unique_words))            # 5 4
print(review.count("หอม"), words.count("หอมมาก")) # 3 2
review_profile = {
    "n_words": len(words),
    "n_unique": len(unique_words),
    "vocab": sorted(unique_words),
    "has_price_word": "ราคาดี" in words,
}
print(review_profile)

# ===== C3 =====
records = [
    {"plot": "RE-001", "actual": 460, "predicted": 450},
    {"plot": "RE-002", "actual": 510, "predicted": 530},
    {"plot": "RE-003", "actual": 395, "predicted": 380},
]
e1 = records[0]["actual"] - records[0]["predicted"]
e2 = records[1]["actual"] - records[1]["predicted"]
e3 = records[2]["actual"] - records[2]["predicted"]
records[0]["error"] = e1
records[1]["error"] = e2
records[2]["error"] = e3

mse  = (e1**2 + e2**2 + e3**2) / 3
rmse = mse ** 0.5
mae  = (abs(e1) + abs(e2) + abs(e3)) / 3
print(records)
print(f"MSE  = {mse:.2f}\nRMSE = {rmse:.2f}\nMAE  = {mae:.2f}")
# MSE = 241.67, RMSE = 15.55, MAE = 15.00
```

**C4** — ตรวจตามเหตุผลการเลือกชนิดข้อมูล ตัวอย่างที่ถือว่าเหมาะสม: list = ลำดับแปลงที่เพิ่ม/ลดได้, tuple = พิกัด GPS หรือ (รหัส, อำเภอ) ที่ไม่ควรแก้, set = พันธุ์ข้าวไม่ซ้ำ, dict = ระเบียนข้อมูลแต่ละแปลงอ้างด้วยชื่อ field
